**Grug Fit for Android** – the same Grug Fit, plus step counting with your phone's built-in step sensor.

**Install:** download `grug-fit.apk` below on your Android phone → open it → allow installs from your browser when asked → Install (choose "Install anyway" if Play Protect asks). Full guide in the app: Settings › Get the Android app.

**Updates:** the screens update themselves from the web. This file only changes for step-counter updates; the app shows a banner when there's a new one. Installing over the old version keeps your data.

**Moving from the Chrome version:** Chrome version › Settings › Backup › Export, then in the app: Home › "Move my data" › Import backup.
